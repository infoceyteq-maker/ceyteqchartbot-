# Security

Please do not report security vulnerabilities in a public issue. Email [info.ceyteq@gmail.com](mailto:info.ceyteq@gmail.com) with the subject `[SECURITY] Ceyteq`, a description, affected version, reproducible steps, and any potential impact. Do not include real customer data or credentials. We will acknowledge and investigate reports as resources permit.

For deployment, use unique API and session secrets, HTTPS, private API/database networking, backups, and least-privilege access. See [the architecture review](docs/ARCHITECTURE.md) for the current trust boundaries and limitations.

General enquiries: [info.ceyteq@gmail.com](mailto:info.ceyteq@gmail.com) · [ceyteq.online](http://ceyteq.online/).
